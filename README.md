# 简历关键词体检器（Resume Scanner）

**一句话**：粘贴简历和岗位 JD，检查关键词匹配度、量化表达、结构完整度，输出打分和改进建议。

**灵感来源**：参考 2026 微信小程序开发大赛「与 AI 共生」方向与腾讯云黑客松《简历制作小能手》的思路，独立设计实现。个人练习项目。

## 怎么用

1. 双击 `index.html`，用 Chrome / Edge 打开
2. 左边粘贴简历纯文本，右边粘贴岗位 JD
3. 点「开始体检」，或点「填入示例」先看效果

## 功能

- **关键词自动提取**：内置 150+ 条产品 / AI / 技术 / 内容 / 软技能词库，加上英文术语识别和高频中文词组，从 JD 中自动提取关键词
- **命中着色**：绿色 = 简历里有，红色 = JD 提到但简历没写
- **四维评分**：关键词覆盖 50% + 量化表达 20% + 结构完整 15% + 表达力度 15%
- **改进建议**：针对性提示，并内置"不要编造"的提醒

## 技术说明

- 单文件、原生 HTML/CSS/JS、零依赖、离线可用、数据不离开本机
- 核心函数 `analyze()` 与 UI 解耦，可用 Node 直接调用测试
- 英文关键词按单词边界匹配（避免 PR 误匹配 Prompt 这类问题）
